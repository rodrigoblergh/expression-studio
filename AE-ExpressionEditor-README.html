AE Expression Editor

Edite, filtre e aplique expressions em múltiplas layers — tudo em um único painel.

⚡ v2.0 🎨 4 temas ⇄ Bulk Replace 🔍 Property Filter

?O que é esta extension?

O AE Expression Editor é um painel CEP (Common Extensibility Platform) para o Adobe After Effects que permite visualizar, editar e aplicar expressions de múltiplas layers e propriedades de uma composição — tudo em um único lugar, sem precisar abrir cada layer individualmente na timeline.

A extension lista as propriedades com expressions, exibe o código completo e oferece ferramentas para buscar, filtrar, modificar e aplicar alterações em massa. A aba Code Editor também permite editar Scripts e Expressions em documentos separados.

📦Instalação

Requisitos

  • Adobe After Effects 2022 ou superior para editar expressions a partir do Scan; versões anteriores ainda precisam de validação prática.
  • CEP extensions habilitadas (debug mode ativo)

Passos

  1. Copie a pasta AE-ExpressionEditor para o diretório de extensions do seu sistema:

    Windows:
    C:\Program Files (x86)\Common Files\Adobe\CEP\extensions\

    macOS:
    /Library/Application Support/Adobe/CEP/extensions/
  2. Habilite extensões não-assinadas adicionando a chave PlayerDebugMode = 1 no registro (Windows) ou no arquivo plist (macOS).
  3. Reinicie o After Effects.
  4. Acesse o painel em Window → Extensions → AE Expression Editor.

⌨Code Editor

Na aba Code Editor, escolha Script para executar um script no After Effects ou Expression para aplicar o código às propriedades selecionadas na timeline. O texto, nome, caminho do arquivo e estado não salvo são guardados separadamente para cada modo.

Open e Recent carregam arquivos; Save grava o documento atual e Save As escolhe outro destino. Alterações não salvas ficam persistidas localmente. Ao substituir um documento, o rascunho anterior pode ser recuperado em Recent → Recover drafts.

A Library guarda snippets de Script e Expression separadamente. Se você editar um snippet e abrir outro, a edição ainda não salva continua disponível ao voltar. Carregar um snippet no editor cria um novo documento sem vínculo com o arquivo que estava aberto.

A marcação local de sintaxe é usada para Expressions quando o projeto está no motor JavaScript. Scripts em ExtendScript e Expressions no motor Legacy são verificados pelo After Effects ao executar ou aplicar, pois usam outra gramática.

⇄Bulk Replace

O modal de substituição em massa é acessado pelo botão ⇄ Bulk Replace na toolbar. Permite alterar múltiplas expressions de uma vez, em todas as layers e propriedades escaneadas.

⚠
Atenção O Bulk Replace atua sobre os dados do último Scan. Sempre faça um Scan antes de usar esta função para garantir que a lista está atualizada.

Modo: Exact Match

Encontra expressions idênticas ao texto digitado no campo "Find" e as substitui pelo conteúdo do campo "Replace". Útil quando a mesma expression se repete em várias layers.

Preview — Exact Match

O Preview mostra o texto completo antes e depois, o destino e o estado habilitado de cada proposta. Também informa os itens ignorados:

  • Propostas: expressions idênticas ao texto buscado que serão alteradas.
  • Itens ignorados: expressions com edição pendente ou código que não pode ser analisado. Matches similares são contados, mas não alterados.

Modo: Pattern (Function Swap)

Substitui o nome de uma função em todas as expressions que a contêm, mantendo os argumentos individuais intactos.

Antes
loopOut("cycle")
loopOut("pingpong")
loopOut("continue")
Depois (Find: loopOut → loopIn)
loopIn("cycle")
loopIn("pingpong")
loopIn("continue")
✓
Dica O Pattern Mode identifica chamadas de função na estrutura do código. Nomes em strings, comentários e declarações não são alterados. Por exemplo, ao buscar loopOut, loopOutDuration não é afetado.

▶Fluxo de trabalho recomendado

  1. Scan — Clique em Scan (ou selecione layers específicas antes de clicar).
  2. Filtrar (opcional) — Use o Property Filter para focar em propriedades específicas, ou o campo de texto para buscar por nome de layer ou conteúdo de expression.
  3. Editar — Clique em uma propriedade para abrir o editor. Edite o código. Use "Show original" para comparar com o estado anterior.
  4. Aplicar — Clique em Apply individual ou use "Apply All" para aplicar todas as mudanças pendentes de uma vez.
  5. Bulk Replace (quando necessário) — Para alterações em massa, abra o Bulk Replace, escolha o modo, faça o Preview e aplique.

💡Dicas e observações

💡
Escopo automático Se você selecionar layers na timeline antes de clicar em Scan, a extension escaneará apenas essas layers. Útil para trabalhar em uma seção específica da comp sem poluir a lista.
💡
Undo no AE Cada "Apply All" e cada operação de Bulk Replace cria um único Undo Group no After Effects. Um único Ctrl+Z no AE desfaz todas as alterações aplicadas naquela operação.
✦
Chips verdes Depois de um Scan, os chips do Property Filter ficam verdes quando aquela propriedade tem ao menos uma expression na composição. Ajuda a identificar rapidamente quais propriedades têm expressions sem precisar escanear.
⚠
Dados do Scan A extension trabalha com o snapshot do último Scan. Se você alterar expressions diretamente no AE (fora da extension), faça um novo Scan para sincronizar os dados.
